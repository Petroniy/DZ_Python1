# Анализ каталога фильмов

Учебный проект для Python 3.12. Решение находится в одном файле
`catalog_analysis.py`. Внешних зависимостей для работы программы нет;
Ruff используется только для разработки.

## Запуск

Из папки проекта:

```console
uv sync --locked
uv run catalog_analysis.py
uv run ruff check .
```

`uv run` сам создает окружение `.venv`, если его еще нет.
Версии зависимостей зафиксированы в `uv.lock`.
